# 00 Project Brief

## One-Line Summary

Ship Design is an AI-powered product design agent system that turns one product idea into a complete, usable design planning package.

## What The Product Does

A user enters a product idea. Ship Design helps them shape that idea into:

- Product strategy
- UX research notes
- User flows
- Screen inventory
- Figma-ready structure
- Design system direction
- Prototype plan
- Landing page strategy
- Developer handoff documentation

## Who It Is For

Primary users:

- Founders validating a new product idea
- Product designers starting a new project
- Product managers preparing a feature or MVP
- Small teams that need clearer design direction

Secondary users:

- Agencies creating early product concepts
- Developers who need better design specs
- Design leads who want repeatable product definition workflows

## Core Problem

Early product ideas are often messy. Teams jump from a vague prompt to screens too quickly, which creates weak product strategy, unclear flows, missing screens, inconsistent design systems, and poor developer handoff.

Ship Design slows the right parts down and speeds the right parts up. It helps the user clarify intent before creating artifacts.

## Product Promise

Turn one product idea into a structured design package that is clear enough to review, edit, prototype, and hand off.

## Desired Experience

The product should feel like a technical command center for product design:

- Structured
- Calm
- Precise
- Fast
- Opinionated enough to guide the user
- Flexible enough to support different product types

## Visual Personality

Ship Design should feel dark, crisp, and technical. It should use acid green as an accent for progress, active state, system signals, and important highlights.

The interface should borrow from CLI and TUI patterns:

- Status labels
- Step counters
- Monospace metadata
- Framed panels
- Grid lines
- ASCII-style separators

## Non-Goals For Now

The first phase should not attempt to:

- Replace Figma
- Replace a human designer
- Generate production-ready frontend code
- Support every product category
- Build a large collaboration system
- Support advanced enterprise permissions

## Success Definition

Ship Design succeeds when a beginner can enter a rough product idea and receive a design package that feels organized, reviewable, and ready for the next step in Figma or implementation.
